# Student Performance Analysis

A Python-based Data Science project that analyzes student academic performance using study hours, attendance, and subject scores.

## Technologies

- Python
- Pandas
- Matplotlib
- Data Analysis
- Data Visualization

## Features

- Dataset exploration
- Statistical analysis
- Average subject scores
- Top-performing students
- Study hours vs performance analysis
- Attendance vs performance analysis
- Correlation analysis
- Data visualizations

## Dataset

The dataset contains:

- Student name
- Study hours
- Attendance
- Mathematics score
- Science score
- English score
